Ember Vault — a top-down stealth game: slip through the Ember Gallery at night, steal 3 ember relics, and reach the green exit unseen. Guards patrol with vision cones, suspicion builds when they see you, and shadow bushes hide you. Toss pebbles to pull a guard away, sneak with Shift, and mind the alarm bar.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network request: the game is plain static files under game/.

## Play

- Move with WASD or arrow keys. Hold Shift to sneak — slower, quieter, harder to spot.
- Click to toss a pebble: guards in earshot go to look where it lands.
- Walk over an ember relic to pocket it. The exit opens once all 3 are taken.
- Get caught by a chasing guard and you lose a life. Three lives, then the heist is over.
- Press P to pause, M to mute.
